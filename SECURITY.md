# Segurança

Encontrou uma falha no jogo, no site ou no repositório? Abra um aviso
privado em **Security → Report a vulnerability** neste repositório (não
abra issue pública). O histórico do último pentest está em
[specs/004-seguranca](specs/004-seguranca/spec.md).

## Correção de conteúdo sobre pessoas reais

O jogo é uma paródia, mas os boxes "Entenda o caso" citam pessoas reais e
resumem reportagens publicadas, com o status de cada apuração. Se você é
uma das pessoas citadas (ou a representa) e encontrou informação errada ou
desatualizada, abra uma issue com o título **"Correção de conteúdo"**
indicando o trecho e a fonte da correção — ou, se preferir não expor o
pedido, use o aviso privado acima. Pedidos com fonte são atendidos na
próxima versão.
