# Retratos próprios (opcional)

Uma imagem PNG aqui substitui o retrato gerado por código (spec 003, RF22).
Use imagem quadrada; ela é exibida com filtro "nearest" (ideal: pixel art).

| Arquivo | Retrato |
|---|---|
| `flavio.png` | procurado (fedora e sobretudo vermelhos) |
| `flavio_oficial.png` | foto oficial de terno |
| `flavio_<id>.png` | disfarçado — ids: turista, motoboy, surfista, magnata, influencer, pagodeiro, piloto, diva |

Regra do LORE: sempre caricatura desenhada, nunca foto real.
